# Airline Crew Scheduling System

## Overview
The Airline Crew Scheduling System is designed to optimize crew allocation and scheduling operations efficiently while satisfying operational constraints.

## Features
- Crew assignment management
- Scheduling optimization
- Conflict handling
- Resource allocation
- Streamlit-based interactive interface

## Tech Stack
- Python
- Streamlit
- Pandas
- NumPy


## How to Run

1. Clone the repository
2. Install dependencies

pip install -r requirements.txt

3. Run the application

streamlit run app.py
